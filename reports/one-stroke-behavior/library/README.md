# 双手规划全库验证

本报告使用冻结的 HumanPlanner，对本地曲库的 MASTER 与 Re:MASTER 分别运行完整规划和实际输入回放。Re:MASTER 为一个完整批次；MASTER 保留先完成的 305 张，再以两个互不重叠的子批次完成其余 604 和 603 张。每个子批次最多并行 4 张谱面，两个子批次合计最多并行 8 张。MASTER 总用时包含原批次、切换和并行补扫的墙钟时间，并非各子批次用时相加。

已解要求全 CP、无缺口，并通过当前速度上限及双手接触机台平面时的手部圆碰撞检查。该模型未验证腕姿、前臂、空中避让或加速度。

接缝统计只覆盖名义路径中前驱和后继唯一的 Slide 衔接。接力表示责任手发生变化，本身不算退步；同手断触与未分配接缝仍需逐谱查看。
