- 0.1.1 Release 构建成功，无编译警告或错误；111 项自动化测试通过。
- 达成率覆盖全部 15 档判定、普通音符权重、Break 额外分、四位截断和重开。18 个真实难度的 Auto Play 均保持满值，无输入全 Miss 均精确归零。

- Windows 原生窗口检查覆盖真实歌曲 ZIP 加载、保留上次歌曲和皮肤、Tap/Touch 流速控件显示。
- 真实设备静音检查覆盖 WAV/MP3/OGG、前导静音、末尾静音、设备时钟、暂停、恢复、重开、异步结束和 SFX 导入。四首 MP3 均实际打开并推进设备位置。未进行扬声器听音或硬件延迟校准。
