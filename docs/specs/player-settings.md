# 播放界面与二级设置

状态：0.2.0 设置面板已实现，实际窗口验收范围见 [0.2.0 记录](../GAMEPLAY-VALIDATION.md)。手部回放显示选项已接入当前开发版，尚未发布。

## 主界面

主界面以圆形游玩画面为主，保留歌曲入口、歌曲与难度信息、模式选择、播放/暂停、重开、进度及必要的结果信息。中央默认显示 DX 减分达成率，计分定义见[达成率契约](achievement.md)。

提供「求解手顺」和「求解示例」入口。生成时暂停；整曲实际输入核验后切换算法游玩，保持暂停供播放。局部无法分配动作时保留缺口，继续生成后续动作；未解或误判音符显示在位置列表和时间轴上，不阻止回放。切换谱面或关闭窗口取消仍在运行的生成，旧任务不能覆盖新谱面的状态。程序异常保留已有输入并报告原因；生成结果的成绩只用于提示，播放必须重新判定。

时间轴支持左键拖动定位、滚轮或按钮缩放、右键拖动平移，以及恢复全曲范围。按下定位时暂停，松开后跳转并保持暂停。跳转重新消费输入到目标时刻，恢复区域、长音符和成绩；丢弃历史单次音效，只恢复仍在持续的 TouchHold 音效。音乐设备丢弃旧缓冲，以目标音乐时间重新计时。负时间预卷和曲末静音尾段也可定位。

提供清晰的“设置”按钮。皮肤、声音和流速不再以多张设置卡片长期占据最左侧；歌曲与模式可保留紧凑入口，不要求另做复杂导航系统。

## 二级设置内容

| 分组 | 内容 |
|---|---|
| 显示 | Tap / Touch 流速及已有的相关显示选项 |
| 皮肤 | 皮肤选择、导入 ZIP、导入目录、素材预览 |
| 声音 | 音乐音量、音效开关与音量、SFX 目录、内置音效 |
| 判定与诊断 | 本阶段实际支持的偏移项、传感区可视化、输入日志入口等调试功能 |

已有默认值和持久化字段由 `AppSettings` 及对应功能代码持有。新增选项必须有实际消费者，不为了照搬上游设置页面加入未实现的选项。设置可以采用一个普通窗口或面板，无需通用配置页面生成器。

显示页提供触区亮起、左右手位和短拖尾开关；区域边界、编号保留在诊断页。手位使用蓝色圆形和橙色菱形，标记大小、描边和拖尾粗细随谱面等比例缩放。悬空时空心；该手在判定器中实际触发外键或内屏区域时填为实心并略微缩小，与触区亮起同步，抬起后恢复原大小。尺寸由 `GameView.DrawHandMarkers` 和 `GameView.DrawHandTrails` 定义，不改变接触面积；不绘制手指轮廓或跟随状态文字。触区填色及拖尾在音符下层，手位也不能盖过音符本体。手顺身份固定，不随手移动到屏幕另一侧而交换。旧日志缺少手位时只显示实际触区，不推测手部轨迹。

## 行为

- 打开设置时暂停游玩及持续音效；关闭后保持暂停，由播放按钮继续。打开设置不能暗中推进或重置谱面、判定和成绩。
- 音量、流速等显示/声音项不改变音符的逻辑时间。皮肤更换只影响显示资源，不改变输入或判定结果。
- 导入需要暂停的资源后保留一致的会话状态，延续现有资源释放和错误反馈。
- 判定规则或输入日志如需重开才能生效，应明确提示并在新一轮生效，不能在一局中静默改变规则。
- 继续保存已有设置，保留上次歌曲、皮肤及音效路径；不能因移动控件丢失原功能。

## 验收

在支持的最小窗口尺寸下，主播放区和播放按钮可用，左栏不再堆满设置卡片。通过设置按钮能找到全部迁移选项；打开、修改、关闭、继续播放以及重启应用后，验证画面、音量和持久化行为。实际检查窗口，不能仅凭 XAML 编译通过宣告界面完成。
